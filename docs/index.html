The problem

Propaganda networks are real, big, and organized

Fake accounts acting together can make a fringe idea look popular.

Method

AI rewording beats text detectors. It doesn't beat behavior.

Copy-paste used to give networks away. Now AI rewrites every post, AI-text detectors fail once text is paraphrased, and reworded propaganda makes false claims seem more widely believed.

So we use no text model. Operators can change their words, but they still share behavior.

Don't ask "was this written by AI?"
Ask "are these accounts working together?"

Five traces we score for every pair of accounts

Same reply targets

Replying to the same messages.

Same timing

Hitting the same post, link or tag within 60 seconds.

Same links & tags

Sharing the same URLs, #hashtags, @mentions or reposts.

Same template text

Identical once case, links, digits, punctuation and emoji are removed.

Same schedule

Matching weekly activity, hour by hour.

From raw posts to ranked groups

01

One table

Every post becomes a row: account, time, text, reply target, links and tags.

02

Shared keys

List each reply target, link, tag and cleaned text, and who touched it.

03

Score pairs

Each shared key adds 1/(sharers − 1), so rare traces count most. Multiply by schedule match.

04

Find groups

Leiden clustering pulls out tight groups of 3 or more accounts.

05

Rank & explain

Rank groups by shared content per member, with the evidence.

Beyond the datasets

Runs live, judges behavior

Live on Bluesky

monitor.py reads Bluesky's public firehose (about 40 posts a second, free, no key), keeps a rolling 24-hour window, and refreshes its report every 5 minutes.

Behavior, not opinions

Like Meta's own policy, the tool flags fake accounts working together. It never scores what a post argues, so it doesn't police viewpoints.

About

Why we built this

Coordinated networks have already changed real elections, and AI now lets them reword every post so copy-paste checks and AI-text detectors miss them. Behind the Accounts looks for what operators can't easily hide: the same reply targets, timing, links, templates and work schedules.

We test it against two datasets with an answer key, Russian Telegram comments with researcher labels and Russian IRA troll accounts on X, and run it live on Bluesky. Built for prairehack26.
